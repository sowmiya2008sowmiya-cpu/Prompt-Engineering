# Prompt Engineering

## Overview
This project explores the concept of Prompt Engineering and the difference between Vague Prompts and Structured Prompts.

## Objective
To understand how clear instructions, context, requirements, and output formats help generate more relevant and organized AI responses.

## Topics Covered
- Prompt Engineering
- Vague Prompts
- Structured Prompts
- Comparison of Prompt Types
- AI-generated Results

## AI Tools Used
- Claude
- Adobe Firefly
- Gemini Flash

## Project Output
The project includes examples of vague and structured prompts along with AI-generated outputs and poster-making activities.

## Conclusion
This project demonstrates that structured prompts can help AI tools produce more focused, relevant, and organized responses.
